# 行业与子行业：分析与估值方法笔记

这个文件夹记录**每个行业、子行业怎么分析、怎么估值**，不是行情记录。
每一篇回答同一组问题，换一个行业，方法就换一套。

价格、财务数据和面板读数会变，所以笔记里的数字都标注日期，只当作例子。
长期有效的是方法、概念和判断依据。

## 约定

- 一个行业（或一个自成体系的子行业）一个文件，文件名用英文小写加连字符。
- 每个结论注明是**数据读到的**，还是**我的推断**，还是**一般性知识，需核对**。
- 不写成投资建议。笔记解释“怎么看”，不给“买不买”。
- 项目的不变量照旧适用（见仓库根目录 `AGENTS.md`）：标的和序列号以
  `config/dashboard.toml` 为准，缺失的数据就写“缺失”，不补一个数。

## 每篇的结构（模板）

1. **怎么赚钱**：收入从哪来，成本是什么，子行业之间怎么不同。
2. **周期性**：驱动盈利起伏的是什么变量（价格、库存、信用、利率、资本开支），和别的周期股有什么区别。
3. **估值方法**：主要看哪几个指标，为什么；哪些常规指标在这里失效；子行业各自的口径。
4. **概念词典**：这个行业特有的词，用一个小例子讲清楚。
5. **常见陷阱**：会让倍数“看起来便宜或贵”的会计、周期和口径问题。
6. **要追踪什么**：先行指标、监管或政策变量、财报里该看的行，以及数据来自哪里。
7. **宏观敏感度**：做过的检验结果，附样本范围和限制。
8. **当前读数（带日期）**：一张快照表，说明它来自哪天。
9. **在 dashboard 里哪里看**：哪个面板，哪些指标这里算不了。
10. **待办与未解决的问题**。
